# 워크숍 검증 섹션 제거 설계

## 목표

워크숍 모듈의 번호가 있는 단계에서 이미 수행한 확인을 문서 끝의 독립된
`## 검증` 섹션에서 반복하지 않도록 한다.

## 범위

- `docs/01-prerequisites.md`부터 `docs/12-cleanup.md`까지 검사한다.
- 현재 `## 검증`이 남아 있는 01~06, 12 모듈에서 해당 섹션 전체를 삭제한다.
- 번호가 있는 단계의 실행 명령, 예상 출력, 브라우저 확인은 유지한다.
- `## 트러블슈팅`과 그 이후 내용은 변경하지 않는다.
- 07~11 모듈은 이미 독립 검증 섹션이 없으므로 내용 변경 대상이 아니다.

## 문서 계약

`scripts/tests`에 01~12 모듈 모두 `## 검증` 제목을 포함하지 않는다는 계약을
추가한다. 테스트를 먼저 실행해 현재 남은 모듈에서 실패하는 것을 확인한 뒤
문서를 수정한다.

기존 명령 설명 계약과 모듈별 문서 계약도 함께 실행하여 단계별 확인 흐름이
손상되지 않았는지 검증한다.

## 완료 조건

- 01~12 모든 모듈에 독립된 `## 검증` 섹션이 없다.
- 단계별 실행·예상 출력·브라우저 확인은 유지된다.
- 트러블슈팅 내용은 변경되지 않는다.
- 전체 `scripts/tests`와 `app/tests`가 통과한다.
- 로컬 `main`과 GitHub `origin/main`이 동일한 커밋을 가리킨다.
